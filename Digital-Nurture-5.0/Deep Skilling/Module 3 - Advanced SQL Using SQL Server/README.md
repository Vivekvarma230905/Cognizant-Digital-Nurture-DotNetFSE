# Advanced SQL Lab Exercises

## Objective
This repository contains solutions for Advanced SQL exercises covering Window Functions, Indexes, Stored Procedures, and User-Defined Functions using MySQL.

## Prerequisites
- MySQL Server 8.0 or later
- MySQL Workbench
- Basic knowledge of SQL

## Database
**employee_db**

## Tables
- Departments
- Employees

## Exercises Completed

### 1. SQL Exercise – Advanced Concepts
**Exercise 1: Ranking and Window Functions**
- Implemented `ROW_NUMBER()`, `RANK()`, and `DENSE_RANK()` functions.
- Ranked employees based on salary.

### 2. SQL Exercise – Index
- Created indexes on employee-related columns.
- Improved query performance using indexes.

### 3. SQL Exercise – Stored Procedure
**Exercise 1: Create a Stored Procedure**
- Created a stored procedure to retrieve employee details based on DepartmentID.

### 4. SQL Exercise – Functions
**Exercise 7: Return Data from a Scalar Function**
- Created a scalar function to calculate the annual salary of an employee.

### 5. SQL Exercise – Stored Procedure
**Exercise 5: Return Data from a Stored Procedure**
- Created a stored procedure to return the total number of employees in a specified department.

### 6. SQL Exercise – Stored Procedure
**Exercise 4: Execute a Stored Procedure**
- Executed the stored procedure using a DepartmentID parameter.
- Displayed employee details for the selected department.

## How to Run
1. Open MySQL Workbench.
2. Execute the SQL scripts in the following order:
   - Database and Tables
   - Sample Data
   - Ranking & Window Functions
   - Index
   - Stored Procedure Exercises
   - Function Exercises
3. Verify the outputs using `SELECT` statements and `CALL` commands.

## Learning Outcomes
After completing these exercises, you will be able to:
- Use SQL Window Functions.
- Create and manage Indexes.
- Create and execute Stored Procedures.
- Develop Scalar Functions.
- Return data from Stored Procedures.
- Work with advanced SQL programming concepts.
