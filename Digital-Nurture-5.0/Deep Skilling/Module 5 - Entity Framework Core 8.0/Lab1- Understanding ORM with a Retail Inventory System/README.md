# Product Management System

## Overview
This project is a simple **Product Management System** developed in **C#**. It demonstrates the use of classes, object-oriented programming concepts, and relationships between products and categories.

## Project Structure

```
├── Category.cs
├── Product.cs
├── README.md
└── lab1.png
```

## Files

### Category.cs
- Defines the `Category` class.
- Stores category information such as Category ID and Category Name.

### Product.cs
- Defines the `Product` class.
- Stores product details such as Product ID, Product Name, Price, and Category.

### lab1.png
- Contains the output screenshot of the program.

## Features
- Create categories.
- Create products.
- Associate products with categories.
- Display product information.
- Demonstrates Object-Oriented Programming (OOP) concepts.

## Technologies Used
- C#
- .NET
- Visual Studio

## How to Run
1. Open the project in Visual Studio.
2. Build the solution.
3. Run the application.
4. View the output in the console.

## Learning Outcomes
- Understanding classes and objects.
- Implementing object-oriented programming.
- Working with relationships between classes.
- Creating and using custom data models.
