# Entity Framework Core Lab Exercises

## Overview
This repository contains a series of Entity Framework Core lab exercises designed to demonstrate the fundamentals of Object-Relational Mapping (ORM), database configuration, migrations, data insertion, and data retrieval using C# and SQL Server.

## Lab Exercises

### Lab 1 – Understanding ORM with a Retail Inventory System
#### Objective
- Understand the concept of Object-Relational Mapping (ORM).
- Learn how Entity Framework Core maps C# classes to database tables.
- Explore entities and their relationships in a retail inventory system.

**Topics Covered**
- Object-Relational Mapping (ORM)
- Entity Classes
- Database Tables
- Entity Relationships

---

### Lab 2 – Setting up the Database Context for Retail Store
#### Objective
- Configure the database context using Entity Framework Core.
- Establish a connection between the application and SQL Server.

**Topics Covered**
- DbContext
- DbSet
- Database Configuration
- Connection String

---

### Lab 3 – Using EF Core CLI to Create and Apply Migrations
#### Objective
- Generate migration files.
- Apply migrations to create the database schema.

**Topics Covered**
- EF Core CLI
- Add-Migration
- Update-Database
- Model Snapshot
- Database Versioning

---

### Lab 4 – Inserting Initial Data into the Database
#### Objective
- Insert records into database tables using Entity Framework Core.
- Perform Create (Insert) operations through C#.

**Topics Covered**
- Create Operation
- Entity Framework Core
- SaveChanges()
- Database Seeding

---

### Lab 5 – Retrieving Data from the Database
#### Objective
- Retrieve records from the database using Entity Framework Core and LINQ.
- Display query results in a console application.

**Topics Covered**
- Read Operation
- LINQ Queries
- Filtering
- Sorting
- Data Retrieval

---

## Technologies Used
- C#
- .NET
- Entity Framework Core
- SQL Server
- LINQ
- Visual Studio

## Learning Outcomes
After completing these labs, you will be able to:
- Understand Object-Relational Mapping (ORM).
- Configure a database context using Entity Framework Core.
- Create and apply database migrations.
- Insert data into SQL Server databases.
- Retrieve and manipulate data using LINQ.
- Build database-driven applications using Entity Framework Core.
