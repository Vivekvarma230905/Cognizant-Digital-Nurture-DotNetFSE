# LINQ Queries with Entity Framework Core

## Overview
This project demonstrates the use of **Language Integrated Query (LINQ)** with **Entity Framework Core** to perform database operations in a C# Console Application. It showcases how to retrieve, filter, sort, and manipulate data using LINQ.

## Project Structure

```
├── Program.cs
├── lab5.png
└── README.md
```

## Files

### Program.cs
- Contains the main application logic.
- Demonstrates various LINQ queries using Entity Framework Core.
- Performs data retrieval, filtering, sorting, and projection.

### lab5.png
- Screenshot showing the output of the LINQ queries.

## Features
- Retrieve data using LINQ
- Filter records with `Where()`
- Sort records using `OrderBy()` and `OrderByDescending()`
- Select specific fields using `Select()`
- Display query results in the console
- Integration with Entity Framework Core

## Technologies Used
- C#
- .NET
- Entity Framework Core
- LINQ
- SQL Server
- Visual Studio

## How to Run
1. Open the project in Visual Studio.
2. Restore the required NuGet packages.
3. Configure the database connection string.
4. Build the project.
5. Run the application.
6. Verify the output shown in `lab5.png`.

## Learning Outcomes
- Understand LINQ syntax and query operators.
- Perform filtering, sorting, and projection using LINQ.
- Integrate LINQ with Entity Framework Core.
- Retrieve and display data efficiently from a database.
