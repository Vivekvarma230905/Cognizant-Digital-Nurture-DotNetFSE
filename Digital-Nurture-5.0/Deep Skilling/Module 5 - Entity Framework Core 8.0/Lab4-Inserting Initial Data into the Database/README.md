# Entity Framework Core CRUD Operations

## Overview
This project demonstrates **CRUD (Create, Read, Update, Delete)** operations using **Entity Framework Core** in a C# Console Application. It shows how to perform database operations through the `DbContext` using Entity Framework Core.

## Project Structure

```
├── Program.cs
├── lab4.png
├── lab41.png
├── lab42.png
└── README.md
```

## Files

### Program.cs
- Contains the main application logic.
- Demonstrates CRUD operations using Entity Framework Core.
- Performs Create, Read, Update, and Delete operations on the database.

### lab4.png
- Screenshot showing the successful execution of the Create operation.

### lab41.png
- Screenshot showing the Read and Update operations.

### lab42.png
- Screenshot showing the Delete operation and the final database state.

## Features
- Create new records
- Read existing records
- Update existing records
- Delete records
- Database interaction using Entity Framework Core
- Console-based application

## Technologies Used
- C#
- .NET
- Entity Framework Core
- SQL Server
- Visual Studio

## How to Run
1. Open the project in Visual Studio.
2. Restore the required NuGet packages.
3. Configure the database connection string.
4. Build the project.
5. Run the application.
6. Verify the outputs using the screenshots (`lab4.png`, `lab41.png`, and `lab42.png`).

## Learning Outcomes
- Understand CRUD operations using Entity Framework Core.
- Perform Create, Read, Update, and Delete operations.
- Work with `DbContext` and entity classes.
- Build database-driven applications using C#.
