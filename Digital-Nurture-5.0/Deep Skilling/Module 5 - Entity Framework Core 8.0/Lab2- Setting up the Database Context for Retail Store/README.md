# Entity Framework Database Context

## Overview
This project demonstrates the use of **Entity Framework Core** by creating and configuring a database context using `AppDbContext`. It provides the foundation for interacting with a database through C# objects.

## Project Structure

```
├── AppDbContext.cs
├── lab2.png
└── README.md
```

## Files

### AppDbContext.cs
- Defines the `AppDbContext` class.
- Inherits from `DbContext`.
- Configures the database connection.
- Manages entity sets (DbSet).
- Enables CRUD operations using Entity Framework Core.

### lab2.png
- Contains the output screenshot of the program.

## Features
- Database context configuration.
- Entity Framework Core integration.
- Database connectivity.
- CRUD operation support.
- Object-Relational Mapping (ORM).

## Technologies Used
- C#
- .NET
- Entity Framework Core
- SQL Server
- Visual Studio

## How to Run
1. Open the project in Visual Studio.
2. Restore the required NuGet packages.
3. Configure the database connection string.
4. Build the solution.
5. Run the application.
6. Verify the output shown in `lab2.png`.

## Learning Outcomes
- Understand Entity Framework Core.
- Configure a `DbContext`.
- Connect a C# application to a database.
- Perform database operations using ORM.
